# Feature Registry — Nexora

| Prefix | Domain |
|--------|--------|
| `FEAT-` | General features |
| `TOOL-` | Tools |
| `AGT-` | Agents |
| `PLG-` | Plugins |
| `PROV-` | Providers |
| `MEM-` | Memory features |
| `UI-` | UI features |
| `SEC-` | Security features |
| `PERF-` | Performance features |
