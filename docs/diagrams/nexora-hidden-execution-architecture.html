Nexora — Hidden Execution Architecture

AI agents execute through an internal sandbox + hidden terminal/runtime. The user interacts only with the Chat/UI; it never runs commands. (Verified DL-045)

UI Is Display-Only

  • • User enters a goal in Chat; never a shell
  • • Activity feed shows tool calls + terminal output
  • • Permission dialogs are approval gates, not command entry
  • • Logs/results surface in chat + Logs tab

Agent Execution Path

  • • Agent → Planner → Workflow → Executor → Tool Mgr
  • • Provider streams committed tool calls
  • • Permission Manager authorizes every call
  • • Reflection/Completion gate loops back to Planner

Hidden Internals + Exception

  • • Terminal, runtimes, sandbox = internal details
  • • Shell/Python/Node/Git/SQLite auto-triggered
  • • Multi-agent: each sub-agent in own sandbox
  • • Browser bridge: host WebView, proxied; egress deny-by-default
