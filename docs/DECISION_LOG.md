Smaller engineering decisions that don't warrant a full ADR.

| Date | ID | Decision | Context | Options Considered | Chosen | Rationale | Impact |
|------|-----|----------|---------|--------------------|--------|-----------|--------|
| 2025-01-15 | DL-001 | Kotlin-only for application code | Java still permitted in build logic and third-party libs | Kotlin-only, Kotlin + Java hybrid | Kotlin-only | Reduces cognitive overhead; Kotlin coroutines/DSLs are core to agent runtime | Build config may still use Groovy/Kotlin DSL; no Java classes in `app/` |
| 2025-01-15 | DL-002 | Jetpack Compose for UI | Need consistent, declarative UI for workspace, terminal, settings | Jetpack Compose, XML layouts, Compose + XML hybrid | Jetpack Compose | Declarative model fits reactive agent state; faster iteration; Material 3 first-class | No XML layout resources; all screens are `@Composable` functions |
| 2025-01-16 | DL-003 | Room for local database | Persist agents, tasks, conversation history, plugin configs | Room, SQLDelight, Realm, SQLite directly | Room | Official Jetpack lib; type-safe DAOs; Compose integration; migration tooling | Schema versioning strategy needed early; DAOs per domain module |
| 2025-01-16 | DL-004 | Hilt for dependency injection | Agent runtime, tool registry, and provider system all need DI | Hilt, Koin, manual DI, Kodein | Hilt | Compile-time safety; Android lifecycle scopes; minimal boilerplate vs manual | `@HiltAndroidApp` entry point; all modules expose `@Provides` |
| 2025-01-17 | DL-005 | OkHttp + Retrofit for networking | LLM provider APIs, plugin HTTP tools, webhook delivery | OkHttp+Retrofit, Ktor, Volley, Fuel | OkHttp + Retrofit | Mature ecosystem; interceptors for auth/logging; suspend function support | Shared `OkHttpClient` singleton; Retrofit interfaces per provider |
| 2025-01-17 | DL-006 | Kotlinx Serialization for JSON | Serialize agent state, tool configs, API payloads | Kotlinx Serialization, Gson, Moshi, Jackson | Kotlinx Serialization | Compile-time codegen; Kotlin-native; no reflection; works with sealed classes | `@Serializable` on all data classes; `Json` instance configured once |
| 2025-01-18 | DL-007 | DataStore for preferences | Store user settings, provider keys, workspace prefs | DataStore, SharedPreferences, encrypted SharedPreferences | DataStore Preferences | Coroutine-native; type-safe; no ANR risk from blocking I/O | Migration path from SharedPreferences not needed (greenfield) |
| 2025-01-18 | DL-008 | Material Design 3 theming | Consistent look across workspace, tasks, terminal, settings | Material 2, Material 3, custom design system | Material 3 (Material You) | Dynamic color support; Compose-native; modern aesthetic | `MaterialTheme` with custom `colorScheme`; dynamic color opt-in |
| 2025-01-19 | DL-009 | Coroutines + Flow for async | Agent execution, streaming LLM responses, UI state | Coroutines+Flow, RxJava, LiveData-only, async/await | Coroutines + Flow | First-party; lightweight; Compose integration via `collectAsState` | All async work uses `suspend`; state exposed as `StateFlow` |
| 2025-01-19 | DL-010 | WorkManager for background tasks | Scheduled agent runs, sync, cleanup | WorkManager, AlarmManager, Foreground Service, JobScheduler | WorkManager | Handles doze/battery optimization; constraints API; backoff built-in | Periodic tasks registered as `PeriodicWorkRequest`; one-off for sync |
| 2025-01-20 | DL-011 | Mermaid for diagram documentation | Architecture and flow diagrams in repo | Mermaid, PlantUML, ASCII art, external images | Mermaid | Renders in GitHub natively; text-based; easy to version | All ADRs and design docs use Mermaid code blocks |
| 2025-01-20 | DL-012 | Conventional Commits for git messages | Consistent changelog generation and history | Conventional Commits, freeform, Angular-style | Conventional Commits | Automates CHANGELOG; enables semantic versioning tooling | `commitlint` config; CI enforces format on PR merge |
| 2025-01-21 | DL-013 | API 34 as minimum SDK | Target modern Android; reduce compat surface | API 26, API 30, API 34 | API 34 (Android 14) | Access to modern APIs (predictive back, photo picker, granular perms) without compat libs | ~35% device coverage at launch; grows over time |
| 2025-01-21 | DL-014 | APK size target < 50MB | Keep install size manageable for on-device delivery | < 30MB, < 50MB, < 100MB, AAB-first | APK < 50MB | Balances feature richness with quick sideload; no Play Store size gate | ProGuard/R8 enabled; resource shrinking per build variant |
| 2025-01-22 | DL-015 | EventBus for inter-module communication | Decouple agent runtime, UI, and plugin system | EventBus, shared Flow, callback interfaces, BroadcastReceivers | EventBus pattern | Decouples modules without circular deps; typed events; easy to audit | Custom sealed `AppEvent` class; central `EventBus` singleton via Hilt |
| 2025-01-22 | DL-016 | NXR- prefix for all error codes | Unified error taxonomy across agent, tools, providers | NEX-, NXR-, APP-, un-prefixed | NXR- | Short, unique, searchable; avoids collision with system codes | All exceptions and error payloads use `NXR-XXXX` format |
| 2025-01-23 | DL-017 | Stable IDs in registries | Agent, tool, and provider registries need stable identifiers | UUID, auto-increment int, domain-prefixed (AGT-001, TOOL-001) | Domain-prefixed stable IDs | Human-readable; debuggable; no collision across registries | Format: `{ENTITY}-{NNN}`; enforced in schema and validation |
| 2025-01-23 | DL-018 | Bottom navigation with 4 tabs | Primary app navigation structure | Bottom nav 4 tabs, drawer nav, top tabs, rail nav | Bottom nav (4 tabs) | Standard Android pattern; thumb-reachable; maps to core user flows | Tabs: Workspace, Tasks, Terminal, Settings |
