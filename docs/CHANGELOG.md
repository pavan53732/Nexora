### Added
- Standing cloud-only AI models rule: DEC-44 elevates the combined DEC-41/DEC-42 boundary into a permanent, non-revisit repository rule (Rule 9 of `AGENTS.md`) — Nexora uses cloud/external AI models only and must never bundle, load, execute, or manage any local AI model or local AI inference runtime (Ollama, LM Studio, GGUF, TFLite, ONNX, or any on-device model). Cloud provider profiles, external endpoint validation, failover, outage degradation, read-only offline behavior, and provider isolation remain planned implementation evidence. Documentation-only; no runtime implementation or executed evidence is claimed.
- No API credit or token-budget limits for the user: DEC-45 confirms that, because the user of the Nexora app is the product owner, the app imposes no API credit limits and no token-budgeting limits on that user — no internal credit balance, spending wallet, cost quota, token ceiling, or automatic cost/token-based execution stop, pause, downgrade, or refusal. Financial and usage information may remain observable but must never become an execution gate for the user. Technical limits that exist for correctness, safety, liveness, and device protection remain mandatory and are not financial credit restrictions. Documentation-only; no runtime implementation or executed evidence is claimed.
- Agent reliability hardening documentation: fixed duplicate Tool timeout and Context freshness declarations; added hierarchical deadline propagation, acceptance-criteria progress vectors, claim-to-evidence binding, non-overridable reasoning ceilings, operation-level unknown-completion reconciliation, deterministic multi-agent conflict abstention, new NFR-REL-016..018 and NFR-CI-003..005 coverage mappings, and E2E-REL-001..009 Android/agent fault-injection journeys.
