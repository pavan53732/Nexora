# UI: Theme — Nexora

## Design System
- Material Design 3 (Material You)
- Dark mode is the **default**.
- Light mode is available via Settings.
- Dynamic colors supported on Android 12+.

## Color Tokens

| Token | Dark | Light |
|-------|------|-------|
| Primary | Nexora Blue (#4FC3F7) | Nexora Blue (#0277BD) |
| Surface | #1E1E1E | #FFFFFF |
| On Surface | #E0E0E0 | #212121 |
| Accent | #00E676 | #00C853 |
| Error | #FF5252 | #D32F2F |
| Warning | #FFD740 | #FFA000 |
| Terminal BG | #0D1117 | #F5F5F5 |
| Code BG | #161B22 | #F8F9FA |

## Typography
- Headings: Roboto / system font, bold
- Body: Roboto / system font, regular
- Code: JetBrains Mono (bundled)
- Terminal: JetBrains Mono

See [Typography.md](Typography.md) for details.
