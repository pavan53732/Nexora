# UI: Typography — Nexora

## Font Stack

| Use | Font | Weight | Size (sp) |
|-----|------|--------|-----------|
| App title | Roboto | Bold | 22 |
| Section header | Roboto | SemiBold | 18 |
| Subtitle | Roboto | Medium | 16 |
| Body | Roboto | Regular | 14 |
| Caption | Roboto | Regular | 12 |
| Code inline | JetBrains Mono | Regular | 13 |
| Code block | JetBrains Mono | Regular | 12 |
| Terminal | JetBrains Mono | Regular | 13 |
| Overline | Roboto | Medium | 10 |

## Bundling
JetBrains Mono is bundled in `assets/fonts/` to avoid depending on system font availability.

## Line Height
- Body text: 1.4x font size
- Code: 1.5x font size
- Headings: 1.2x font size
